Item Description Maker

Generates blank, fillable versions of 5e.tools' own ve-stats markup — matches its look automatically wherever that styling is already active in your Foundry.

Saved Items

    • Blank line = new paragraph
    • **text** = bold, *text* = italic
    • [[text]] = accent-colored link-style highlight (like "Concentration" in the sample)
    • - item on its own lines = bullet list
    • > text on its own line = blockquote
    • ## Sub Title starts a named sub-entry (like "Sense Thoughts.") — keeps absorbing following lines/paragraphs until the next ## or the end

    Blocks

    A Feature is a stat-block card (spell or not) matching the 5e.tools structure. A Text block is plain text between features — use > text for a blockquote transition like "Additionally, as an action, Cast Foresight".
